# SP4RK

Discord-бот для организации ивентов гильдии. Полностью переписан на модульную архитектуру, с поддержкой нескольких игр и одной командой на весь функционал.

## Требования

- Python 3.11 или 3.12. **Не ставь на Python 3.13+** - discord.py всё ещё тянет модуль `audioop`, который Python удалил из стандартной библиотеки начиная с 3.13. На 3.11/3.12 всё работает без танцев с бубном.
- PostgreSQL 16 (поднимается через `docker-compose.yml`).
- Пакеты из `requirements.txt`.

## Запуск

```bash
cp .env.example .env
nano .env

docker compose up -d
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
alembic upgrade head
python main.py
```

## Discord-права, которые нужны боту

- **Message Content Intent** - без него не заработает загрузка картинок для баннеров и иконок классов (бот ждёт следующее сообщение с вложением в канале).
- **Manage Events** - право на сервере, нужно, чтобы бот мог создавать и обновлять нативные события Discord для каждого ивента. Без этого права ивенты всё равно будут работать, просто без записи в календаре сервера.
- Обычные права на отправку сообщений, вложений и управление сообщениями в тех каналах, где будут появляться карточки ивентов.
- Иконки классов создаются как emoji приложения бота - это действие авторизуется самим токеном бота, отдельных прав на сервере под это не нужно.
- Команда `/spark` по умолчанию видна только тем, у кого есть право "Управлять сервером" (это настройка Discord, её можно донастроить в интеграциях на сервере). Внутри бота действует ещё и своя проверка - через роли администраторов SP4RK.

## .env

```env
DISCORD_TOKEN=твой_токен
DATABASE_URL=postgresql+asyncpg://spark_user:spark_password@localhost:5432/spark_db
TIMEZONE=Europe/Moscow
SYNC_COMMANDS=true
DEBUG=false
LOG_FILE=logs/sp4rk_errors.log
GUILD_NAME=Stormchasers

DEFAULT_REMINDER_MINUTES=30
DEFAULT_EVENT_DURATION_MINUTES=180
EPHEMERAL_DELETE_AFTER=60
RAID_PURGE_AFTER_HOURS=24

BANNER_STORAGE_DIR=storage/banners
BANNER_WIDTH=900
BANNER_HEIGHT=260
BANNER_UPLOAD_TIMEOUT_SECONDS=120
BANNER_MAX_UPLOAD_MB=15

BRAND_COLOR=0x5865F2
BOT_STATUS=✨ Записываем на ивенты
```

`TIMEZONE` - часовой пояс, в котором бот понимает дату и время, введённые при создании ивента. По умолчанию Europe/Moscow, и в этой версии он общий для всех админов - персональный часовой пояс на пользователя убран за ненадобностью, потому что игроки и так видят время в своём поясе через метку Discord.

`RAID_PURGE_AFTER_HOURS` - через сколько часов после **окончания** ивента (старт плюс длительность) карточка удаляется из чата и из базы. По умолчанию 24 часа. `EPHEMERAL_DELETE_AFTER` отдельный и относится только к скрытым (эфемерным) уведомлениям бота - подтверждениям и подсказкам, его трогать не обязательно.

`BANNER_STORAGE_DIR` - папка на диске, где хранятся уже обработанные картинки баннеров. Если разворачивать бота в Docker, нужно примонтировать эту папку как volume, иначе баннеры пропадут при пересборке контейнера.
