# SP4RK — Stormchasers Raid Helper

Discord-бот для организации событий Where Winds Meet в гильдии Stormchasers.

## Что внутри

- Python 3 + discord.py.
- PostgreSQL через SQLAlchemy async + asyncpg.
- Alembic-миграции.
- Redis через Docker Compose.
- APScheduler для напоминаний, закрытия и очистки событий.
- Запись участников только через кнопки.
- Администрирование через `/spark`.

## Основные возможности

- `/spark создать-событие` отправляет публичную карточку события в выбранный канал.
- Участники используют кнопки: записаться, отменить запись, возможно буду, запасной, точно не буду.
- Кнопка `ЛС-уведомление` позволяет участнику включить или отключить напоминание по конкретному событию.
- По умолчанию ЛС-напоминание включено и стоит за 30 минут.
- Регистрация закрывается за 1 минуту до начала.
- После старта событие архивируется и пропадает из списка активных.
- Через 1 час после старта событие удаляется из базы.
- Если карточка события вручную удалена из Discord, SP4RK удаляет событие из базы и не отправляет напоминание.
- Команды администрирования доступны администраторам сервера, пользователям с правом `Управлять сервером` и ролям, добавленным через `/spark добавить-роль-админа`.
- Логи ошибок можно скачать командой `/spark логи`.

## Запуск

```bash
cp .env.example .env
nano .env

docker compose up -d
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
alembic upgrade head
python main.py
```

## .env

```env
DISCORD_TOKEN=твой_токен
DATABASE_URL=postgresql+asyncpg://spark_user:spark_password@localhost:5432/spark_db
REDIS_URL=redis://localhost:6379/0
TIMEZONE=Europe/Moscow
SYNC_COMMANDS=true
DEBUG=false
LOG_FILE=logs/sp4rk_errors.log
DEFAULT_REMINDER_MINUTES=30
GUILD_NAME=Stormchasers
```

## Обновление старой базы

После замены проекта обязательно выполнить:

```bash
alembic upgrade head
```

Новая миграция добавляет:

- роли администрирования SP4RK;
- пользовательское включение/отключение ЛС-уведомлений.

## Логи

Обычный спам APScheduler скрыт при `DEBUG=false`.
Ошибки и предупреждения пишутся в:

```text
logs/sp4rk_errors.log
```

Скачать файл можно через Discord:

```text
/spark логи
```


## Новое: общий лимит события

В команде `/spark создать-событие` появился параметр `лимит_участников`. Значение `0` означает отсутствие общего лимита. Если основной состав заполнен, SP4RK предлагает игроку выбрать класс для записи в запас.


## Обязательный лимит события

В команде `/spark создать-событие` параметр `лимит` обязателен. Это общий лимит основного состава события. Если основной состав заполнен, SP4RK предлагает пользователю записаться в запас.

## Обновление этой сборки

После замены файлов выполните:

```bash
pip install -r requirements.txt
alembic upgrade head
python main.py
```

Основные команды теперь приведены к единому виду:

```text
/spark класс-добавить
/spark класс-удалить
/spark класс-показать-все
/spark событие-создать
/spark событие-создать-из-шаблона
/spark событие-показать-все
/spark событие-редактировать
/spark событие-удалить
/spark шаблон-создать
/spark шаблон-показать-все
/spark шаблон-редактировать
/spark шаблон-удалить
/spark роль-админа-добавить
/spark роль-админа-удалить
/spark роль-админа-показать-все
/spark логи
```

В `.env` можно менять:

```env
DEFAULT_REMINDER_MINUTES=30
EPHEMERAL_DELETE_AFTER=60
BOT_STATUS=✨ Работаю вместо Джета.
DEBUG=false
```
